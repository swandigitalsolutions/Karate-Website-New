# Discipline Karate Institute

Website for Discipline Karate Institute, Devanahalli — traditional karate led by Shihan Dr. N. Murali.

Built with React 19, Vite, GSAP (ScrollTrigger) and Lenis smooth scrolling. Served in production by a small Express server.

## Run locally

Requires Node.js 22+ and pnpm.

```bash
pnpm install
pnpm dev        # http://localhost:3000
```

## Production

```bash
pnpm build      # builds the site to dist/public and the server to dist/index.js
pnpm start      # serves dist/ (sets long-lived cache headers for hashed assets)
```

## Editing content

- `client/src/data/site.ts` — phone, WhatsApp, email, address, hours, map location, social links
- `client/src/data/content.ts` — all page copy: programs, milestones, medallists, press, gallery, FAQ

The enquiry form has no backend: it opens WhatsApp with the visitor's details pre-filled, sent to the number in `site.ts`.

## Images

Original photos live in `source-images-original/`. The site uses optimised copies generated by:

```bash
python scripts/build-images.py   # requires Pillow with AVIF support
```

This writes AVIF + WebP files in several widths to `client/public/images/` and regenerates `client/src/data/images.ts` (dimensions and inline blur placeholders). To add or swap a photo, edit the `IMAGES` table in the script, run it, and reference the image by name.
